# Security

KUE is a private assistant that keeps a person's data on their own Mac. A weakness that lets data leave the machine, lets a model decide or act, or lets an action run without the owner's approval is the most serious kind.

## Reporting a weakness

Please do not open a public issue. Use **Report a vulnerability** on the Security tab of this repository. It opens a private report that only the owner can read.

Say what you found, how to reproduce it, and what it could expose. You will get an answer, and credit if you want it. There is no bounty.

## What is in scope

- The code in this repository.

## What is not

- A Mac that is already under someone else's control.
- Third-party packages. Report those to their own maintainers, and tell us if KUE uses them in an unsafe way.
